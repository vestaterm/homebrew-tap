# Vesta Homebrew tap

```sh
brew install --cask vestaterm/tap/vesta-terminal
```

Installs [Vesta](https://github.com/vestaterm/Vesta) — a native macOS terminal with
persistent sessions, cmux-style workspaces, and Lua plugins — plus the `vesta` CLI
on your PATH. Signed + notarized; upgrades via `brew update && brew upgrade --cask vesta-terminal --greedy` or the
app's built-in updater.

The cask is bumped automatically by Vesta's release workflow.
